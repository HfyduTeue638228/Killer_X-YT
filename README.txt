How to Build Your APK for FREE on GitHub:

3. Extract this ZIP and drag & drop everything INSIDE the "killer-x-yt" folder (app, build.gradle.kts, settings.gradle.kts, gradle.properties, README.txt) -> Commit changes.
4. If ".github" folder was skipped during web upload, click "Add file" -> "Create new file", name it ".github/workflows/build-apk.yml" and paste the workflow content from .github/workflows/build-apk.yml -> Commit changes.
5. Open the "Actions" tab -> wait 2-3 minutes -> download "Killer-X-YT-APK" from Artifacts -> extract and install "Killer-X-YT-v1.0.apk"!
